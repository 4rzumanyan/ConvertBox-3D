# ConvertBox 3D

ConvertBox 3D is a Microsoft Word add-in (macro-enabled template) for working with Armenian, Russian and English text. It adds three ribbon tabs to Word: **Convert Number**, **Convert Date** and **Convert Text**. The ribbon interface itself can be switched between English, Armenian and Russian.

## Features

**Convert Number**
- Spell numbers as words in English, Armenian or Russian.
- Add currency names (AMD, USD, EUR, RUB, GEL, UAH) or a custom unit and subunit, with options for fractions and remainders.
- Spell all numbers in a selection at once, or one by one.
- Convert numbers to Armenian or Roman numerals, and back to Arabic numerals.

**Convert Date**
- Insert the current date in English, Armenian or Russian, either short or fully spelled out.
- Convert a date to text with configurable input and output formats.
- Insert the day or week number of the year.
- Convert years to the Armenian calendar.

**Convert Text**
- Convert Armenian and Russian text between ANSI fonts and Unicode, for a selection, a whole document or several files at once.
- Transliterate Armenian or Russian text, and convert Azerbaijani, Russian or Georgian text to Armenian script.
- Translate text, change case, reverse text, count word frequency and preview the installed fonts.

## Installation

1. Download [`ConverterBox 3D.dotm`](https://github.com/4rzumanyan/ConvertBox-3D/blob/main/ConverterBox%203D.dotm?raw=true).
2. Follow the [installation video](https://github.com/4rzumanyan/ConvertBox-3D/blob/main/ConvertBox%203D%20installation%20instruction.mp4?raw=true) to add the template to Microsoft Word.
3. Enable macros for the template when Word asks. The ConvertBox tabs will appear on the ribbon.
